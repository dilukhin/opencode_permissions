# YC59: воспроизводимый библиотечный компонент

`tools/build_yc_owner_component.py` собирает ровно семь файлов владельца и
точного профиля чтения. Manifest связывает размеры, SHA-256, ограничения и
незавершённые условия одним идентификатором `yc_owner_component.v1`.
Значения `status=library_only` и `execution_enabled=false` входят в этот хеш.
Изменить их без смены идентичности нельзя. Сборщик не меняет прежнюю политику,
не добавляет deployable-профиль и не упаковывает публичный approve CLI.

Команды сборщика: без аргументов — manifest; `--write <новый каталог>` —
сборка в отсутствующий каталог; `--check <каталог>` — точная проверка.
Существующий каталог не перезаписывается и не ремонтируется. Изменение payload,
manifest, лишний файл или ссылка вызывают отказ.

Toolchain независимо проверяет этот компонент и умеет подготовить его
**неактивную** копию. Проверенная копия не считается доверенным размещением,
источником native veto или разрешением на запуск. Установка рабочего владельца
остаётся закрыта до защищённого bootstrap, доверенных ReadContext/native veto,
функции spawn и управляемой активации с установленной приёмкой.

Описание библиотечного host и происхождения Ledger:
`docs/yc59_bounded_owner_runtime_ru.md`. Границы подготовки у toolchain:
`docs/yc59_owner_component_staging_ru.md` в `dilukhin/agent-toolchain`.
