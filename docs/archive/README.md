# Historical project documents

Этот каталог хранит superseded документы ранней стадии проекта.

Они сохранены как historical/evidence material, чтобы не терять исходные решения и контекст, но **не являются нормативными источниками**.

Актуальные документы находятся в корне репозитория:

- `opencode_permissions_project_baseline_ru.md` — нормативный persistent baseline;
- `opencode_permissions_chatgpt_web_guide_ru.md` — правила работы из ChatGPT Web;
- `opencode_permissions_agent_guide_ru.md` и `AGENTS.md` — правила локального агента;
- `chatgpt_project_instructions_seed_ru.md` — переносимая копия Project Instructions;
- `opencode_permissions_findings_ru.md` — historical/evidence findings.

При противоречии archived-документа с актуальным baseline или фактическим состоянием реализации использовать актуальный источник.
